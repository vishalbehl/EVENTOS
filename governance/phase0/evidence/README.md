# Phase 0 Evidence Store

Status: READY FOR EVIDENCE COLLECTION

This directory stores the evidence used to close Phase 0. Evidence must be
dated, attributable, reproducible, and free of raw credentials.

## Directory Layout

```text
evidence/
  secrets/      Rotation records and negative-authentication proof
  scans/        Raw scanner output and scan summaries
  retests/      Remediation and Critical/High retest records
  screenshots/  Redacted provider or secret-manager screenshots
```

Run repository-local checks from the repository root:

```powershell
powershell -ExecutionPolicy Bypass -File governance/phase0/evidence/run-local-security-scans.ps1
```

The runner creates a timestamped directory under `scans/`. A scan marked
`SKIPPED` is missing evidence, not a pass. API/DAST scanning requires an
explicit test or staging URL:

```powershell
powershell -ExecutionPolicy Bypass -File governance/phase0/evidence/run-local-security-scans.ps1 `
  -ApiTargetUrl http://localhost:8000 `
  -ContainerImage Event-backend:phase0
```

## Evidence Rules

- Never store raw secret values, bearer tokens, private keys, cookies, or
  unredacted personal data.
- Use fingerprints, key IDs, provider request IDs, and redacted screenshots.
- Keep raw failed output as well as the successful retest.
- Record tool version, scope, command, timestamp, repository commit, operator,
  result, and output path.
- External-provider screenshots must show the account/environment and rotation
  timestamp without exposing the credential.
- Independent assessor approval remains external evidence and cannot be
  generated by this repository.
