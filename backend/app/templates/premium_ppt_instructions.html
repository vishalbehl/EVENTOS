Presentation Preparation

How to Prepare Your Presentation

 

Preparation Checklist

  • Recommended slide ratio: 16:9
  • Embed fonts and media to prevent display issues
  • Keep videos lightweight and avoid excessive animations
  • Confirm slides, links and demos before final delivery

Presentation Upload Guide

  • Upload the latest presentation version
  • Use supported formats such as PPTX, PDF, Keynote (for MAC) when requested
  • Use Video Formatting like MP4, MOV, M4A etc, and Image formatting like JPEG, PNG etc
  • You can also Upload Full Folder which includes all your files. (Just make sure that do not upload all session ppts in one folder.)
  • Each session file/folder must be uploaded seperately. 
  • Apply a clear file naming convention with speaker and session title
  • Meet upload deadlines and replace older files only through the defined update process

Speaker Ready Room (SRR) Guide

 

Before You Present

  • Visit the SRR before your session starts
  • Check in using the QR code provided
  • Preview the final uploaded presentation
  • Test videos and all media playback
  • Complete final confirmation with the event team

On-Stage Guidelines

  • Arrive before your scheduled session time
  • Use the assigned microphone as briefed by the technician
  • Advance slides with the provided presentation clicker
  • Follow session timing and moderation cues
  • Contact the stage technician immediately if you need assistance
 
 

Stage Walkthrough & Session Guide

Hybrid Session Guidelines

 

Remote-Aware Tips

  • Stay aware of camera placement for live streaming
  • Acknowledge virtual attendees when prompted
  • Optimize video and screen sharing for streamed viewing
  • Use concise transitions and pauses for remote participants
